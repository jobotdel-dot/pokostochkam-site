## Калькуляторы

**Страница:** https://jobotdel-dot.github.io/calcs.html — шесть инструментов:

| # | Калькулятор | Что считает | Норма |
|---|---|---|---|
| 1 | УСН 6% против 15% | полная нагрузка с учётом НДС, взносов и минимального налога | ст. 346.11, 346.13, 346.16, 346.18 НК РФ |
| 2 | Пени по налогу | трёхступенчатый порядок для организаций, 1/300 для ИП | ст. 75 НК РФ |
| 3 | Взносы ИП «за себя» | 57 390 ₽ + 1% свыше 300 000 ₽, неполный год, потолок | ст. 430 НК РФ |
| 4 | НДС | выделить и начислить, ставки 22/10/7/5/0% | ст. 164, 168, 170 НК РФ |
| 5 | Аванс по УСН | база без НДС и налог 6% отдельно | ст. 346.21, 346.22 НК РФ |
| 6 | Штраф за декларацию | 5% за месяц, не менее 1 000 ₽, не более 30% | ст. 119 НК РФ |

**Как это устроено:**

- результат показывает **расчёт по шагам** (кнопка «Показать расчёт по шагам») — видно, какое
  число из какого получилось;
- под каждым результатом — **норма НК РФ** и ссылка на первоисточник;
- если ввод вызывает вопросы (превышен порог НДС, расходы больше доходов, доход без НДС
  при пороге, просрочка 0 месяцев) — **предупреждение**, а не молчаливый результат;
- все нормативы 2026 года собраны в одном объекте `RATES` в начале `app.js` — легко
  обновить, когда нормативы поменяются;
- расчёты идут **полностью в браузере**, ничего никуда не отправляется.

**Нормативы, зашитые в код (2026):** НДС 22% (10% для социальных товаров, 5% и 7% для
упрощенцев), порог дохода для освобождения от НДС на УСН — 20 млн ₽, фиксированные взносы
ИП — 57 390 ₽, дополнительный 1% — потолок 321 818 ₽, МРОТ — 27 093 ₽, ключевая ставка
ЦБ — 14%, предел пени для организаций на 31–90-й день — 1/150 ключевой ставки.

**Проверка арифметики:**


Эталоны взяты из калькулятора пеней biznesinalogi (НДС 500 000 ₽, 51 день, 14% →

## Вебмастер Яндекса

Подробная инструкция — в `YANDEX-WEBMASTER.md`. Коротко:

```bash
# подтверждение прав: код берётся из Вебмастера («Подтвердить права» → «Файл»)
node tools/yandex-verify.mjs "yandex-verification-code-123.html:a1b2c3d4"

# работа с API Вебмастера (нужен OAuth-токен из настроек)
$env:YANDEX_WEBMASTER_TOKEN = "ваш-токен"
node tools/yandex-api.mjs all          # sitemap + переобход + статистика
node tools/yandex-api.mjs status       # сколько URL в индексе

# проверка индексации снаружи, без Вебмастера
node tools/check-index.mjs
```

Что уже задеплоено и работает: `robots.txt` (открыт, ссылка на sitemap),
`sitemap.xml` (10 URL), `canonical` на всех страницах, микроразметка Schema.org,
`og-image.png`, `favicon.svg`, `404.html`, RSS `feed.xml`.

## Правила содержания

1. **Ни одной цифры без первоисточника.** Любая ставка, лимит, срок и номер статьи
   сверяются с текстом акта (шаг 2 выше даёт сканы страниц для сверки).
2. **Дата проверки** и пометка «Материал подготовлен с помощью ИИ и проверен редактором»
   — на каждой странице.
3. **Три примера расчёта** с реальными числами. Это то, ради чего читатель приходит.
4. **Источники** — НПА, номера пунктов, ссылки.
5. **Дисклеймер** — обязателен.
6. **Регулярность 3 статьи в неделю.** Больше не успеете сделать ручную сверку,
   а формальная сверка = «малополезный контент» по критериям Яндекса.

## Правовые рамки

- **243-ФЗ от 26.07.2026, ст. 9** — маркировка материала, созданного с помощью ИИ.
  Для обычного текстового блога формального требования нет; пометка оставлена добровольно.
  <https://rg.ru/documents/2026/07/31/fz243-dok.html>
- **Ч. 9 ст. 13.15 КоАП РФ** — распространение заведомо недостоверной информации
  под видом достоверной. Отсюда правило «ни одной цифры без первоисточника».
  <https://sudact.ru/law/koap/razdel-ii/glava-13/statia-13.15/>
- **ГК РФ ст. 1228** — авторское право: автором признаётся лицо, создавшее результат
  творческим трудом. Используются только официальные документы.
- **38-ФЗ ст. 18.1** — маркировка рекламы (ЕРИР): нужен `erid`, когда появится реклама.
- **Поисковики:** Google — *scaled content abuse*
  (<https://developers.google.com/search/docs/essentials/spam-policies>),
  Яндекс — «малополезный контент»
  (<https://yandex.ru/support/webmaster/ru/threat/useless-content>).
