# Ежедневная публикация: инструкция и автозапуск

## Как это работает

```
                    ┌──────────────────────────────────────┐
каждый день 07:00 ──▶ tools/daily.mjs                       │
                    │  • сбор тем с pravo.gov.ru и RSS ФНС   │
                    │  • отбор новой темы (3 фильтра)        │
                    │  • заготовка в out/daily/             │
                    └───────────────┬──────────────────────┘
                                    │
                                    ▼
                    ┌──────────────────────────────────────┐
вы (или ИИ)       ──▶ пишете текст в src/NN-тема.md        │
                    └───────────────┬──────────────────────┘
                                    ▼
                    ┌──────────────────────────────────────┐
                    │ tools/lint-article.mjs                │
                    │ проверка: цифры, примеры, язык, ссылки │
                    └───────────────┬──────────────────────┘
                                    ▼
                    ┌──────────────────────────────────────┐
                    │ tools/publish-article.mjs             │
                    │ вёрстка → микроразметка → якоря →     │
                    │ перелинковка → sitemap → RSS → главная │
                    │ → push в GitHub                       │
                    └───────────────┬──────────────────────┘
                                    ▼
                    через 1–3 минуты сайт обновлён
```

**Важно:** автоматизация заменяет рутину, но не проверку. Текст статьи и
проверка цифр — всегда за человеком. Это не формальность: без сверки
материал попадёт под фильтр Яндекса «малополезный контент», и потеряете всё
разом. Скрипт `daily.mjs` собирает **темы**, а не пишет статьи.

## Команды

### Ежедневный сбор тем (можно запускать автоматически)

```bash
cd C:\Users\jobot\OneDrive\Dokumentumok\deepseek-harness\pokostochkam-site
node tools/daily.mjs
```

Что делает:
1. обновляет очередь тем `out/topics.md` и `out/topics.json`;
2. выбирает тему, которой ещё нет в блоге;
3. кладёт заготовку в `out/daily/NN-тема.md` с первоисточником, датами,
   регистрацией Минюста и планом по шагам.

### Написать статью

Файл — в `default-workspace/blog-usn-2026/src/NN-тема.md`.
Структура и требования — в `EDITORIAL.md`.

### Проверить

```bash
node tools/lint-article.mjs src/NN-тема.md
```

Линтер не пропустит статью, если:
- нет блока `:::example` с разбором расчёта;
- меньше 8 чисел в тексте;
- нет ссылок на нормы и на первоисточник;
- «около 1000 ₽» вместо точной цифры;
- нет дисклеймера;
- канцелярит и длинные предложения (это замечания, не блокировка).

### Опубликовать

```bash
node tools/publish-article.mjs src/NN-тема.md
```

Одна команда делает всё: линт → вёрстка → микроразметка → якоря →
перелинковка → sitemap → RSS → карточка на главной → push в GitHub.

Если статья ещё не готова — проверить без публикации:

```bash
node tools/publish-article.mjs src/NN-тема.md --no-push
```

## Автозапуск в Windows (Планировщик задач)

### Вариант 1. Создать задачу вручную

1. Откройте **Планировщик заданий** (Win + R → `taskschd.msc`).
2. **«Создать задачу»** → вкладка «Общие»:
   - Имя: `Косточки — ежедневный сбор тем`
   - «Запускать только при входе в систему» или «Выполнять только по зарегистрированному пользователю».
3. Вкладка **«Триггеры»** → «Создать…»:
   - «Ежедневно», время **07:05**.
4. Вкладка **«Действия»** → «Создать…»:
   - Программа: `C:\Program Files\nodejs\node.exe`
   - Аргументы: `tools\daily.mjs`
   - Начало в: `C:\Users\jobot\OneDrive\Dokumentumok\deepseek-harness\pokostochkam-site`
5. Вкладка **«Общие»** → «Снять галочку» *«Выполнять только при входе в систему»*
   и поставить **«Выполнять задачу, даже если компьютер не включён»** —
   тогда задача запустится при следующем включении.
6. **ОК** → введите пароль Windows.

### Вариант 2. Создать задачу одной командой

```powershell
$action = New-ScheduledTaskAction -Execute "C:\Program Files\nodejs\node.exe" `
  -Argument "tools\daily.mjs" `
  -WorkingDirectory "C:\Users\jobot\OneDrive\Dokumentumok\deepseek-harness\pokostochkam-site"
$trigger = New-ScheduledTaskTrigger -Daily -At 7:05am
$settings = New-ScheduledTaskSettingsSet -StartWhenAvailable -DontStopIfGoingOnBatteries -AllowStartIfOnBatteries
Register-ScheduledTask -TaskName "Косточки — ежедневный сбор тем" `
  -Action $action -Trigger $trigger -Settings $settings `
  -Description "Ежедневный сбор тем с pravo.gov.ru и RSS ФНС, подбор новой темы"
```

Проверить, что задача создалась:

```powershell
Get-ScheduledTask -TaskName "Косточки*" | Select-Object TaskName, State
```

Запустить вручную (не дожидаясь 07:05):

```powershell
Start-ScheduledTask -TaskName "Косточки — ежедневный сбор тем"
```

Удалить:

```powershell
Unregister-ScheduledTask -TaskName "Косточки — ежедневный сбор тем" -Confirm:$false
```

### Проверить, что задача отработала

```powershell
Get-ScheduledTaskInfo -TaskName "Косточки — ежедневный сбор тем" |
  Select-Object LastRunTime, LastTaskResult, NextRunTime
```

`LastTaskResult = 0` — отработала без ошибок.

## Почему компьютер должен быть включён

GitHub Pages пересобирает сайт после push — это 1–3 минуты. Пока компьютер выключен,
статья не появится на сайте. Варианты:

| Вариант | Плюсы | Минусы |
|---|---|---|
| Включённый компьютер | просто | нужна включённая машина |
| Задание «при входе в систему» | запустится, когда вы зашли | если не заходите — не запустится |
| Облачный CI (GitHub Actions) | работает без компьютера | нужна настройка workflow-файла |

Для ежедневной публикации разумнее оставить публикацию ручной (она и так
требует проверки), а автоматизировать **сбор тем** — он не зависит от вашего
внимания.

## Сбор тем — без вашего участия

`daily.mjs` обращается к официальным источникам:
- `publication.pravo.gov.ru` — акты ФНС, Минфина, Минэкономразвития,
  Правительства, Минтруда, Минюста;
- RSS ФНС России — `nalog.gov.ru/rn77/rss/`.

Скрипт **ничего не выдумывает**: в заготовку попадают только номер акта,
даты, регистрация в Минюсте и ссылка на первоисточник. Текст статьи пишется
человеком.

## Если что-то пошло не так

**Сбор тем вернул 0 тем** — проверьте интернет и вывод команды:
```bash
node tools/collect-topics.mjs 45
```

**Линтер ругается на статью, а она готова** — посмотрите, что именно:
```bash
node tools/lint-article.mjs src/NN-тема.md
```
Блокирующие замечания (`✗`) останавливают публикацию. Замечания (`!`) — на ваше
усмотрение; обойти можно флагом `--force`.

**Сайт не обновился после push** — подождите 1–3 минуты и проверьте:
```bash
node tools/check-live.mjs
```

**Ошибка EPERM при запуске** — это ограничение песочницы, а не ошибка скрипта.
В обычном терминале Windows всё работает.
